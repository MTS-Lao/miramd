# MiraMD 0.1.0

The first Developer ID signed and Apple-notarized macOS release of MiraMD.

## Install on macOS

Download **MiraMD-0.1.0-macOS-arm64.dmg**, open it, and drag **MiraMD** onto the **Applications** shortcut. Then launch MiraMD from Applications.

- Requires **macOS 14 or later** on an **Apple Silicon Mac** (M1 or newer).
- Signed with Developer ID Application, notarized by Apple, and distributed with a stapled notarization ticket.
- A checksum is provided in `SHA256SUMS.txt`.

## Included

- Visual editing, Markdown source, split view, and formatted reading mode.
- Light, dark, and system appearance.
- Folder workspace and document outline.
- Microsoft Word DOCX import and export with Lao and Unicode support.
- Phetsarath Lao display font and Phetsarath OT metadata for Word export.
- Offline code syntax highlighting and clean Markdown exports for AI tools.
- Local MCP tools restricted to user-approved folders.

## Windows

The existing Windows x64 build is available in the [Windows Preview 4 release](https://github.com/MTS-Lao/miramd/releases/tag/v0.1.0-preview.4). This release adds the notarized Mac installer; it does not replace the Windows preview build.
