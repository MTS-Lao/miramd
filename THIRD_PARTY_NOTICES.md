# Third-party notices

## Phetsarath Lao

MiraMD bundles the Phetsarath Lao web/app font for displaying Lao text. The font is Lao-only by design, so English and other scripts fall through to each platform's native UI fonts.

- Source: <https://fonts.mts.la/f/phetsarath-lao>
- Catalog: <https://fonts.mts.la/api/fonts.json>
- License: SIL Open Font License 1.1
- Copyright and reserved font-name notices remain those declared by the font publisher.

MiraMD's Microsoft Word exporter intentionally uses the separate `Phetsarath OT` family, as recommended for Office documents.
