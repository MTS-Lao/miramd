# ຄູ່ມື MiraMD

MiraMD ຊ່ວຍໃຫ້ຄົນອ່ານ ແລະ ແກ້ໄຂເອກະສານ Markdown ໄດ້ງ່າຍ ໂດຍບໍ່ຈຳເປັນຕ້ອງຮຽນຮູ້ເຄື່ອງໝາຍທັງໝົດ.

## ຄຸນສົມບັດ

- ອ່ານເອກະສານດ້ວຍຮູບແບບທີ່ສວຍງາມ
- ສ້າງຫົວຂໍ້, **ຕົວໜາ**, *ຕົວອຽງ*, ລາຍການ ແລະ ຕາຕະລາງ
- ສົ່ງອອກເປັນ Microsoft Word ໂດຍຮັກສາ Unicode ແລະ ການຕັດຄຳພາສາລາວ

| ຮູບແບບ | ຮອງຮັບ |
|---|---|
| Markdown | ແມ່ນ |
| Microsoft Word | ແມ່ນ |

> ຂໍ້ຄວາມພາສາລາວຈະຖືກກຳນົດເປັນ complex script ເພື່ອໃຫ້ Microsoft Word ຕັດຄຳໄດ້ຖືກຕ້ອງ.
